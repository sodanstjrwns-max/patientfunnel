### 2️⃣ THERMO — "마음의 온도" 스크롤 온도 시스템 🌡️

**컨셉**: 페이션트 퍼널 = 환자 마음의 온도가 올라가는 여정. 스크롤 깊이 = 퍼널 깊이 = 마음의 온도(36.5° → 99.9°). 페이지가 아침 종이처럼 밝게 시작해 스크롤할수록 노을 → 황혼 → 밤으로 깊어지며, 마지막엔 별이 뜬 밤하늘에서 "팬이 되는 순간"을 맞이.

**5단계 페이즈 (`html[data-phase="0~4"]`):**
| Phase | 스크롤 | 이름 | 무드 |
|---|---|---|---|
| 0 | 0% | 첫 만남 | 아침 종이 (아이보리) |
| 1 | 18% | 관심 | 오후 (따뜻한 크림) |
| 2 | 40% | 신뢰 | 노을 (앰버) |
| 3 | 62% | 확신 | 황혼 (다크 반전 시작) |
| 4 | 82% | 팬이 되다 | 밤 (근흑색 + ⭐별빛 필드) |

**구현 파일:**
- `css/thermo.css` (~8.5KB) — 페이즈별 토큰 오버라이드(0.9s 전환), 다크 페이즈 버튼/버거/티커/슬라이더/셀렉션 보정, 밤 별빛 `body::after` radial-gradient, 온도 게이지 위젯 스타일, `prefers-reduced-motion` 대응
- `js/thermo.js` (~2.6KB) — rAF 스크롤 엔진: ratio 계산 → `data-phase` 토글 → 온도(36.5→99.9°) 실시간 보간 → 게이지 색상(그린→앰버→레드) 갱신

**UI 요소:**
- 좌하단 고정 **온도 게이지** (`#thermoGauge`): 온도계 아이콘 + "마음의 온도" + 현재 온도 + 페이즈명 + 프로그레스 바 (스크롤 3% 이후 표시)
- 히어로 온도 내러티브: "처음 만난 환자의 마음은 36.5°입니다..."
- 피날레 배지 (`.finale__thermo`): "마음의 온도 99.9° — 환자가 팬이 되는 순간"
